# Frame Animation Preview Tool

[中文](README.md)|English

A visual frame animation playback tool that supports importing image sequences for frame-by-frame preview.

![Screenshot](屏幕截图.png)

## ✨ Features
- 📤 Drag & drop or click to upload image sequences (PNG / JPG / GIF / WebP)
- 🎬 Play / Pause / Frame navigation, adjustable FPS (1–60)
- 🔍 Fullscreen zoom mode, scroll wheel scaling and drag panning
- 🎨 One-click toggle between dark / light themes
- ⌨️ Full keyboard shortcuts (Space for play, arrow keys for frame switch, F for fullscreen, etc.)
- 📊 Frame indicator dots and thumbnail strip for quick jump
- 💾 Auto-save theme preference

## 📦 Download & Installation
Download from [Releases](https://github.com/Jade-Cyan/FrameAnimationPreviewTool/releases):
- `Frame Animation Preview Tool Setup x.x.x.exe` — Installer version
- `FrameAnimationPreviewTool-Portable-x.x.x.exe` — Portable version (no installation required)
